### 🌟 [Project_X](https://github.com/Gen-2k/Project_X) — Enterprise-Grade TypeScript Monorepo

[![License: MIT](https://img.shields.io/badge/License-MIT-F59E0B.svg?style=flat-square)](https://opensource.org/licenses/MIT)
[![TypeScript 5](https://img.shields.io/badge/TypeScript-5.x-3178C6?style=flat-square&logo=typescript&logoColor=white)](https://www.typescriptlang.org/)
[![React 19](https://img.shields.io/badge/React-19.x-06B6D4?style=flat-square&logo=react&logoColor=black)](https://react.dev/)
[![NestJS 11](https://img.shields.io/badge/NestJS-11.x-E0234E?style=flat-square&logo=nestjs&logoColor=white)](https://nestjs.com/)

</div>

> ⚡ **Project_X** is a cutting-edge, production-ready full-stack monorepo designed with strict architectural boundaries, automated CI/CD validation gates, end-to-end type safety, and blazing fast build caching via **Turborepo** and **pnpm**.

| Architecture Layer | Technology Stack | Key Capabilities |
| :--- | :--- | :--- |
| 🖥️ **Client App** | React 19 · Vite 8 · Vitest · Tailwind | Instant HMR, Modern React hooks & concurrent features, component testing |
| ⚙️ **Backend API** | NestJS 11 · Prisma 7 · Jest | Modular architecture, dependency injection, high-performance DB queries |
| 📦 **Shared Packages** | Configs · DTOs · Linting Rules | Zero-duplication TS configurations, shared validation schemas & typings |
| 🛡️ **DevOps & CI/CD** | GitHub Actions · Docker · Turborepo | Parallelized test suites, hermetic docker builds, remote caching |
